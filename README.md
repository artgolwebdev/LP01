## ✨ Features

- 🎨 **Cyberpunk Design** - Neon lights & futuristic aesthetics
- 📱 **Fully Responsive** - Optimized for all devices
- ⚡ **Fast Performance** - Built with Vite
- 🎵 **Interactive Audio** - Background audio controls
- 📧 **Contact Form** - PHP backend with email
- 🔗 **Social Ready** - Optimized meta tags for sharing

## 🚀 Quick Start

```bash
npm install
npm run dev
```

## 🏗️ Build

```bash
npm run build
npm run preview
```

## 🎯 Tech Stack

- **Frontend**: React 18 + TypeScript + Tailwind CSS
- **Build**: Vite + SWC
- **UI**: Radix UI primitives
- **Backend**: PHP + Mailgun
- **Styling**: Custom CSS variables

## 📧 Setup

1. Copy `env.example` to `.env`
2. Configure Mailgun settings
3. Update domain URLs in `index.html`

## 🌐 API

- **Endpoint**: `POST /api/ContactFormHandler.php`
- **Required**: `name`, `email`
- **Optional**: `phone`, `message`

## 🚀 Deploy

- **Frontend**: Vercel, Netlify, GitHub Pages
- **Backend**: Any PHP server (Apache/Nginx)
